# Todo App

A simple and modern Todo List web application built with HTML, CSS, and JavaScript.

The application allows users to create and manage daily tasks through a clean and responsive interface.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by:
  - All
  - Active
  - Completed

- Clear all completed tasks
- Display the number of remaining tasks
- Save tasks using Local Storage
- Light and dark mode
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Git & GitHub
- GitHub Pages

## How It Works

Users can enter a task in the input field and click **Add Task**.

Each task can then be:

- Marked as completed
- Deleted
- Filtered depending on its status

Tasks are stored in the browser's Local Storage, so they remain available after refreshing or reopening the page.

The application also includes a light/dark theme toggle.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or external dependencies are required.
